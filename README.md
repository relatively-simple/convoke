## 🌟 Overview & Elevator Pitch

Most people interact with AI through static chat boxes that suffer from five critical flaws:
1. **Prompt Guesswork:** When a prompt is vague, AI models hallucinate assumptions instead of asking what you actually need.
2. **Single-Model Fragility:** If OpenAI, Google, or Groq suffers an outage or hits a rate-limit, your workflow halts completely.
3. **Dead Text Walls:** Complex systems, mathematics, and algorithms are dumped as static markdown blocks instead of runnable, tangible prototypes.
4. **Single-AI Bias:** Relying on one model leads to blind spots and unverified assertions.
5. **Device Lock-In:** Chat history is trapped in a single browser session on one computer, lost whenever you switch devices.

**Convoke 3.0 is an autonomous multi-model workspace designed to solve these fundamental bottlenecks.** It combines an intelligent edge router with cross-device account sync (Google & Email), multi-model self-improvement deliberation for visual simulations, client-side zero-knowledge privacy masking, parallel AI Boardroom deliberation, and an isolated execution canvas that runs live HTML5/JavaScript, Three.js 3D graphics, KaTeX math, and Python in WebAssembly.

## 🚀 Key Features in Convoke 3.0

### 🏛️ Tri-Model Architecture & Free Community Tier
Convoke 3.0 is engineered with a powerful dual-tier architecture:
- **Convoke 3.0 Pro Tri-Model Engine (Flagship Architecture):** Harnesses the trifecta of frontier AI—**OpenAI ChatGPT (o1 / GPT-4o)** for rigorous multi-step logic, **Google Gemini 2.0 Pro** for vast multimodal context, and **Anthropic Claude 3.7 Sonnet** for elite coding and structural design.
- **Free Community Tier (Active Live Demo):** An ultra-fast, zero-friction edge router powered by **Groq (GPT-OSS 120B / Qwen 2.5)**, **Google Gemini Flash**, and **NVIDIA NIM DeepSeek**. Instant sub-5-second inference with zero user subscription required.
- **2-Try Model Failover:** If any model times out (15s deadline) or errors twice, Convoke automatically advances to the next best provider without interrupting your flow.

### 🎨 Multi-Model Visual Self-Improvement Deliberation
Instead of returning flat, static diagrams, Convoke 3.0 executes an automated self-improvement design deliberation between models before generating visual software:
1. **Google Gemini (Physical Foundations):** Formulates the governing physical laws, spatial coordinate geometry, formulas, and boundary states.
2. **Groq (Dynamic Animation Loop):** Designs a continuous 60 FPS numerical animation loop (`requestAnimationFrame`) with dynamic vector fields, particles, and flow.
3. **NVIDIA NIM (Interactive Agency):** Adds interactive parameter sliders (`<input type="range">`), clickable canvas probes, material presets, and synchronized live readouts.
4. **Synthesized Artifact:** Generates a full, responsive HTML5 Canvas simulation that users can interact with directly in the canvas.

### ✍️ Live Typewriter Behind-the-Scenes Progress Stream
No more frozen 100% loaders. Convoke 3.0 features a subtle, glowing typewriter status stream that displays the exact behind-the-scenes thoughts, multi-model deliberation steps, and runtime checks letter-by-letter in real time.

### 🗑️ Clean Chat Thread Deletion
Easily delete any unwanted chat thread or experiment with a subtle, non-intrusive trash button on hover/focus in the sidebar and conversation toolbar, complete with safety confirmation.

### 🌐 Cross-Device Google & Email Account Sync
No longer bound to a single computer's browser cookie:
- **Sign in with Google:** One-click Google account connection.
- **Sync with Email:** Enter your email on any computer, tablet, or phone to access all your saved projects and chat threads.
- **Automatic Migration:** Existing guest chats on your computer are automatically transferred into your account upon signing in.

### 🎯 Thorough Mode & Clarification Quiz
When starting a new project with **Thorough Mode** enabled:
- Convoke analyzes your prompt for architectural gaps, target audience, technical constraints, workflows, and edge cases.
- Presents an interactive clarification quiz with up to 12 missing decisions, providing multiple-choice recommendations and custom inputs.
- Once answered, Convoke builds the complete solution without repeated interrogation.

### ⚖️ Multi-Model AI Boardroom
When facing high-stakes architectural or product decisions:
1. **Parallel Independent Drafting:** 3 models independently draft solutions in isolation.
2. **Anonymous Peer Review:** Each model cross-examines its peers' proposals, highlighting hidden edge cases, failure modes, and omissions.
3. **Chairman Synthesis:** A designated chairman model synthesizes the strongest elements into an authoritative verdict.

### 🛡️ Client-Side Zero-Knowledge Privacy Proxy
Before any prompt leaves your browser:
- Detects sensitive entities: credit cards (Luhn validated), API keys, bearer tokens, SSNs, phone numbers, and emails.
- Replaces them locally with typed cryptographic masks (`[CREDIT_CARD_1]`, `[API_KEY_1]`).
- The AI only ever sees the masked tokens. When the response returns, Convoke automatically re-hydrates the original data locally on your device.

## 🛠️ Tech Stack & Architecture

- **Frontend & App Framework:** React 19, Vite 8, Tailwind CSS, Lucide Icons, Sonner.
- **Edge Runtime:** Cloudflare Workers (SSR + Static Asset streaming).
- **Persistent Storage:** Cloudflare D1 (serverless globally distributed SQLite).
- **Client Execution Sandbox:**
  - Sandboxed iframe with strict Content Security Policy (`default-src 'none'`).
  - **Pyodide (WebAssembly):** In-browser Python runtime with standard library and assert validation.
  - **Three.js:** Inlined 3D WebGL runtime.
  - **KaTeX:** High-speed mathematical typesetting.

## 📦 Local Development

### 1. Prerequisites
- Node.js 20+ (v24 recommended)
- Cloudflare Wrangler CLI (`npm i -g wrangler`)

### 2. Installation
```bash
git clone https://github.com/relatively-simple/convoke.git
cd convoke
npm install
```

### 3. Environment Configuration
Create a `.dev.vars` file in the root directory:
```env
# Optional provider keys (at least one recommended for live AI responses)
GROQ_API_KEY=your_groq_api_key
GEMINI_API_KEY=your_gemini_api_key
NVIDIA_API_KEY=your_nvidia_api_key

SESSION_SECRET=a_random_32_character_secret_string_here
AUTH_MODE=public
```

### 4. Run Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🚀 Cloudflare Deployment

Deploy to your own Cloudflare account in under 3 minutes:

```bash
# 1. Build the self-hosted distribution
npm run build:selfhost

# 2. Deploy to Cloudflare Workers
npm run deploy:selfhost
```

Your app will be live at `https://convoke.<your-subdomain>.workers.dev` with a globally replicated D1 SQLite database and edge worker.
